月底不要再翻整個群

LINE 收來的單，月底怎麼對帳

對帳不是比誰比較記得。要先留下客人確認過的單、每次修改，再把同一段期間的紀錄整理到一起。

作者：訂單秘書2026-09-05

一句話

LINE 訂單要能對帳，關鍵不是月底才整理，而是接單時留下客人確認與每次修改；月底再選期間匯出 CSV，用 Excel 按客戶與狀態篩選，對不上時能查回原單。

月底客人說「我明明有訂」，你往上翻 LINE，只找到他曾經打過一句話。這還不夠。中間有沒有改數量、你抄進 Excel 時有沒有漏、最後出的是哪一版，都可能沒留下來。

從接單當下留到月底
  1. 對不上從哪裡開始
  2. 留下可查的紀錄
  3. 匯出 CSV 整理
  4. 不算錢的界線
  5. 好對帳表的重點
  6. 常見問題

對不上，通常不是月底那一天才出問題

第一個根源是訊息散在群裡。同一家客戶可能下午先叫幾樣，晚上補一段，隔天早上再改一個數量。叫貨旁邊還夾著問價和其他對話。月底只用關鍵字搜尋，找到的是一則訊息，不一定是最後成立的訂單。

第二個根源，是從 LINE 抄到紙本或 Excel 的過程沒有留痕。你看到「兩箱」抄成「一箱」，表格只留下最後的數字，看不出當時怎麼來的。客人拿聊天畫面，你拿自己抄的表，兩邊都覺得手上的東西才對。

第三個根源，是改過的單沒人記得誰改的。客人原本訂五包，後來電話裡說改三包；店裡有人改了出貨單，另一個人仍照原訊息備貨。到了月底，只剩「我記得有講」對上「我記得有改」。這不是 Excel 公式能補救的，是接單當下就少了一段紀錄。

先把每一筆單變成可以回頭看的紀錄

訂單秘書先把客人在 LINE 群裡的口語叫貨整理成訂單卡，回在同一個群。客人看過品項、數量與單位，按「✓ 沒錯」。這個動作不是付款，也不是簽名；它的用途是留下「客人看過這張整理後的單」的節點。

之後如果有人在訂單台修改，改動會留下紀錄。月底回頭看時，可以分清楚客人當時確認了什麼，以及後面哪裡又變過。這比從聊天裡截一張圖完整，因為截圖往往只截到最早那句，沒有後續處理。

如果你現在還是每天人工抄單，可以先讀訂單秘書怎麼處理 LINE 口語叫貨。飲料與酒水經銷常遇到一張單很多行、單位又混在一起，也可以看飲料・酒水經銷的收單場景。

選一段期間匯出 CSV，再進 Excel 整理

到了對帳時間，在訂單台選要核對的期間，匯出 CSV。CSV 是一份表格資料，Excel 可以直接打開。你不用把每一則 LINE 訊息重新複製貼上，也不用一張訂單卡一張訂單卡手抄。

匯出內容會帶著對帳需要的訂單資料。可用「客戶、日期、品項、數量、單位、狀態」這些通用概念理解，但實際欄位名稱與內容，以當下匯出檔為準。不要先假設一定有某一欄，再拿自己的表格硬套。

先篩期間與狀態，不要一打開就開始加

第一步先確認日期範圍是不是這次要對的月份或結算區間。接著看狀態，把取消、未成立或需要另外確認的紀錄分開。對帳最怕把不該算的單也加進去，最後總數很漂亮，範圍卻錯了。

再按客戶分組，一家一家核對

用 Excel 篩選某一位客戶，照日期排序。這樣可以先看這家在期間內每一天訂了哪些品項，再跟你原本的出貨或帳務資料核對。遇到爭議時，不要只丟整份月表給客人，先縮到那一家、那幾天，問題會比較容易看清楚。

資料多時，用樞紐分析看彙總

如果筆數多，可以插入樞紐分析表。操作邏輯是把客戶放在列，品項或日期放在下一層，再把數量放到值區。你也可以先用篩選只留一位客戶，再看他整段期間的品項加總。不同單位不要硬加在一起；斤、箱、簍要分開看，換算仍照你店裡原本的規則。

樞紐分析拿來找總量，原始列則拿來查細節。當某個數字對不上，從彙總往下找到那一天、那一筆，再回看客人確認與修改紀錄。這樣對帳是沿著紀錄找原因，不是回到群裡憑印象猜。

先講清楚：訂單秘書不算錢

訂單秘書不算金額、不開發票、不收款，也不替你做應收帳款。它給你的是「誰在什麼時候訂了什麼」的紀錄，包含客人確認過的訂單卡與後續修改。

單價、折讓、稅額、發票與收款，還是照你原本的作法。匯出的 CSV 可以當對帳底稿，不能把它當成完整會計帳。你若要的是從接單一路算到財務，應該找處理那一整段的系統，不要期待一份訂單紀錄自動變成帳。

一份好對帳表，重點不是欄位多

真正有用的是每一列能往回查。這筆是哪位客戶、哪一天、什麼品項與單位，客人有沒有確認，之後有沒有改。只要這條線連得起來，月底遇到不同說法，就有共同的東西可以看。

反過來說，欄位再多，如果來源只是某天晚上重新抄過的 Excel，仍然回答不了「原本怎麼訂、後來誰改」。所以改善對帳要從接單當下開始。先讓口語訊息變成確認過的訂單，再談匯出與樞紐分析。想比較這種做法跟其他接單工具的差別，可以看LINE 接單系統怎麼選。

LINE 訂單對帳常見問題

LINE 訂單可以匯出給 Excel 打開嗎？

可以。訂單秘書可以選一段期間匯出 CSV，Excel 可直接開啟。實際欄位以當下匯出檔為準。

客人說「我明明有訂」，要看哪一份紀錄？

先看那一筆訂單卡是否由客人按過「✓ 沒錯」，再看後續修改紀錄。這能釐清當時確認的內容與之後改過的地方，不必只靠聊天印象。

CSV 匯出後，怎麼按客戶分開對帳？

可在 Excel 用篩選先限定日期與狀態，再按客戶分組；資料較多時可用樞紐分析，把客戶放在列、品項或日期放在下一層，數量放在值區。

訂單秘書會算金額、開發票或收款嗎？

不會。它保留的是誰在什麼時候訂了什麼，以及確認與修改紀錄。金額計算、發票與收款仍照你原本的作法。
